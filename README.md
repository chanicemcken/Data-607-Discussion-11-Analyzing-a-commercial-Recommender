# Data-607-Discussion-11-Analyzing-a-commercial-Recommender
Reverse Engineering Pinterest's Recommendation System: Scenario Design, User Experience, and Recommendations

For this assignment, I selected Pinterest's recommendation system because it provides personalized content based on users' interests, searches, and saved Pins.

I used Scenario Design to examine the system from both the user's and the organization's perspectives. My analysis also explores what can be learned about Pinterest's recommendation process through its interface, public documentation, and engineering publications.

Based on my research, I recommend improving personalization controls, increasing content diversity, providing clearer recommendation explanations, and evaluating success beyond short-term engagement.

My Quarto report includes the Scenario Design analysis, an overview of the recommendation process, limitations, and proposed improvements.
